# Docker Full-Stack Authentication System

A Dockerised authentication system built with **.NET 8, React, PostgreSQL, and Docker Compose**.  
The project demonstrates user registration, login, JWT authentication, and user profile retrieval.

---

## Tech Stack

### Frontend
- React
- TypeScript
- Axios

### Backend
- .NET 8 Web API
- Entity Framework Core
- JWT Authentication

### Database
- PostgreSQL

### Infrastructure
- Docker
- Docker Compose

---

## Features

✔ User registration  
✔ User login with JWT tokens  
✔ Protected user details page  
✔ PostgreSQL database  
✔ Dockerised environment  
✔ CORS configuration  
✔ Integration tests (optional)

---

## Running with Docker (Recommended)

Make sure Docker Desktop is running, then:

```bash
docker compose up --build
```
